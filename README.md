# Gestiona-Informacion-Mediante-Software-en-linea
Repositorio para ejercicios y pruebas de la materia de Gestiona Informacion Mediante Software en linea 

GIT Hub

CARACTERISTICAS principales de GitHub
1. Control de versiones con Git

Registrar cambios en archivos.

Volver a versiones anteriores.

Comparar modificaciones.

Trabajar en paralelo sin sobrescribir trabajo.


VENTAJAS
Facilita el trabajo colaborativo.

Guarda el historial completo de cambios del proyecto.

Permite recuperar versiones anteriores del código.

Almacena proyectos en la nube.

Acceso desde cualquier lugar con internet.

Permite trabajar con ramas (branches) sin afectar el proyecto principal.

Incluye herramientas para revisión de código (Pull Requests).

Automatiza tareas con GitHub Actions.

Integra herramientas de seguridad y detección de errores.


DESVENTAJAS

Tiene una curva de aprendizaje para principiantes.

Algunos comandos de Git pueden ser complicados.

Los conflictos de merge pueden ser difíciles de resolver.

Requiere internet para aprovechar la mayoría de funciones online.

Existe riesgo de publicar información privada por error.

Algunas funciones avanzadas son de pago.
