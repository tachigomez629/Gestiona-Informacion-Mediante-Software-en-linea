# Gestiona-Informacion-Mediante-Software-en-linea
Repositorio para ejercicios y pruebas de la materia de Gestiona Informacion Mediante Software en linea 
CARACTERISTICAS DE HIT HUB
Control de versiones con Git
Permite registrar cambios en el código y volver a versiones anteriores si es necesario.
Repositorios remotos
Los proyectos se almacenan en la nube y pueden ser públicos o privados.
Trabajo colaborativo
Varias personas pueden trabajar simultáneamente en el mismo proyecto.
Branches (ramas)
Facilitan desarrollar nuevas funciones sin afectar el código principal.
Pull Requests
VENTAJAS
Facilita el trabajo en equipo
Historial completo de cambios
Respaldo del código en la nube
Gran comunidad de desarrolladores
Ideal para proyectos de código abierto
Automatización de procesos
DESVENTAJAS
Curva de aprendizaje inicial
Git y GitHub pueden resultar difíciles al principio.
Dependencia de internet
Muchas funciones colaborativas requieren conexión.
Privacidad limitada en planes gratuitos
Algunas funciones avanzadas son de pago.
Conflictos de versiones
